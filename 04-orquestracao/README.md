# ☸️ Orquestração com Kubernetes

## O que é Kubernetes?

Kubernetes (K8s) é uma plataforma de orquestração de containers de código aberto que automatiza o deploy, scaling e gerenciamento de aplicações containerizadas.

## 🎯 Objetivos de Aprendizado

Ao final deste módulo, você será capaz de:

- Entender os conceitos fundamentais do Kubernetes
- Criar e gerenciar clusters Kubernetes
- Deployar aplicações no Kubernetes
- Gerenciar networking e storage
- Implementar monitoramento e logging
