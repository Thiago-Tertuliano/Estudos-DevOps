# 🔒 Segurança em DevOps (DevSecOps)

## O que é DevSecOps?

DevSecOps é a integração de práticas de segurança no processo de desenvolvimento e operações, garantindo que a segurança seja considerada desde o início do ciclo de vida do software.

## 🎯 Objetivos de Aprendizado

Ao final deste módulo, você será capaz de:

- Entender os princípios de DevSecOps
- Implementar segurança em containers
- Gerenciar secrets de forma segura
- Automatizar testes de segurança
- Implementar compliance e auditoria
