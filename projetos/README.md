# 🚀 Projetos Práticos de DevOps

Esta pasta contém projetos práticos para aplicar os conceitos aprendidos nos módulos de estudo.

```
projetos/

```

## 🎯 Projetos Disponíveis

### 1. Hello World Container

**Nível**: Iniciante  
**Tecnologias**: Docker, Docker Compose  
**Objetivo**: Criar seu primeiro container e entender os conceitos básicos

### 2. Aplicação Web Completa

**Nível**: Intermediário  
**Tecnologias**: Docker, Kubernetes, CI/CD  
**Objetivo**: Deploy de uma aplicação web com banco de dados

### 3. Microserviços

**Nível**: Avançado  
**Tecnologias**: Kubernetes, Service Mesh, Monitoring  
**Objetivo**: Arquitetura de microserviços com observabilidade

### 4. Stack de Monitoramento

**Nível**: Intermediário  
**Tecnologias**: Prometheus, Grafana, ELK Stack  
**Objetivo**: Implementar observabilidade completa

### 5. Pipeline CI/CD

**Nível**: Intermediário  
**Tecnologias**: GitHub Actions, Docker, Kubernetes  
**Objetivo**: Automação completa de build, test e deploy

### 6. Full Stack DevOps

**Nível**: Avançado  
**Tecnologias**: Todas as tecnologias estudadas  
**Objetivo**: Projeto completo com todas as práticas DevOps

## 🚀 Como Usar

1. **Escolha um projeto** baseado no seu nível atual
2. **Siga as instruções** do README de cada projeto
3. **Experimente e modifique** o código
4. **Documente suas descobertas** no seu log de estudos

## 📝 Log de Estudos

Mantenha um arquivo `meu-log.md` para documentar:

- O que você aprendeu
- Desafios encontrados
- Soluções implementadas
- Próximos passos
