# 🐳 Containerização com Docker

## O que é Containerização?

Containerização é uma tecnologia de virtualização que permite empacotar aplicações e suas dependências em containers isolados, garantindo que funcionem de forma consistente em qualquer ambiente.

## 🎯 Objetivos de Aprendizado

Ao final deste módulo, você será capaz de:

- Entender os conceitos de containerização
- Usar Docker para criar e gerenciar containers
- Criar Dockerfiles eficientes
- Usar Docker Compose para orquestrar múltiplos containers
- Implementar boas práticas de containerização
